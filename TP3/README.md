# Character Manager — TP3 (Java Visual)

## Deskripsi

Project Character Manager merupakan program berbasis Java yang dibuat untuk memenuhi tugas TP3 AP3 Belajar Praktik. Program ini menggunakan konsep Object-Oriented Programming (OOP), seperti class, object, constructor, encapsulation, dan enum.

Program ini juga memiliki fitur tambahan berupa atribut mana dan method isAlive() untuk memeriksa kondisi karakter.
